# Business OS

A simple business management platform for small businesses — sales, products &
inventory, customers, expenses, invoices, and profit/loss reports in one place.

**Stack:** Next.js · TypeScript · Tailwind CSS · Supabase (Postgres + Auth) · Vercel · Stripe (planned)

**Status:** 📋 Planning — see [docs/TECHNICAL_PLAN.md](docs/TECHNICAL_PLAN.md) for the full
technical plan (architecture, schema, auth, RLS, phases). No implementation yet;
the plan is awaiting approval.
